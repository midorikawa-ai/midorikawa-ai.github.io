PRIVACY POLICY

python プライバシーポリシー

適用日：2026年10月31日

1. 対象と利用目的

本ポリシーは、Tomoe Midorikawa が個人で運用する Windows アプリ「python」と、この案内サイトに適用します。アプリは運用者本人が許可したデータを、保存、検索、索引作成、分類、内容確認、分析に利用します。一般向けサービスではありません。

2. Gmail へのアクセス

Gmail の読み取り専用権限 gmail.readonly を使用します。メールのヘッダー、本文、添付ファイルを含む EML 原形式を保存します。検索用の索引には、件名、差出人、宛先、CC、日時、スレッド情報、本文全文、要約・分類の項目、添付関連のメタデータなどを保持します。この権限を使って元メールを変更・削除・送信することはありません。

3. 保存、同期、外部での分析

取得したメールと索引は、本人が管理する Windows 環境と保存領域で扱います。日次処理では、本文全文を含む索引データベースのコピーを Google Drive の同期フォルダーへ置き、既存のファイル同期経路を利用します。これは、Drive API による文書取得とは別の経路です。

本人が確認した検索結果を CSV 形式で書き出し、Drive 経由で ChatGPT の Project に渡して分析に利用する補助経路があります。このため、すべてのデータがローカルだけに保存・処理されるわけではありません。外部処理は、本人が確認した目的に必要な範囲とし、Google のデータ利用条件に適合する処理条件を確認して利用します。

この公開サイトに、メール、添付ファイル、検索結果、業務文書、認証情報を掲載することはありません。

4. Google Drive 文書取得

読み取り専用権限 drive.readonly による文書の変更確認と自動取得の運用を開始しました。

この権限自体は Drive 全体を読み取れるもので、Google 側の許可が特定フォルダーだけに限定されるわけではありません。アプリ側で本人指定のフォルダー配下に対象を制限し、文書内容、名称、識別子、更新・版情報を取得する設計です。元文書の編集・移動・削除は行いません。保存済み文書の更新時には旧版を保持します。

5. 保持、削除、接続解除

現在、保存メールと索引に一律の自動保存期限は設けていません。Gmail 側でメールが削除されても、保存済みの EML を連動して削除する運用ではありません。

Google アカウントの接続管理から本アプリのアクセスを取り消せます。ただし、接続解除だけでは保存済みのメール、索引、同期コピー、分析用の書出し結果や旧版は消えません。削除は、これらの保存先を区別して本人が管理・確認します。外部サービス側のコピーについても、各サービスの管理機能と条件に従って確認します。

6. 利用目的の制限と認証情報

Google API から得た情報の利用および他アプリへの転送は、Limited Use 要件を含む Google API Services User Data Policyに従います。広告、販売、データ仲介、信用判定、非個人向けの汎用 AI・機械学習モデルの開発・改善・学習を目的とした利用・提供は行いません。外部サービスを使う場合も、この制限に適合する処理条件を確認します。

Google へのアクセスには OAuth を使用します。認証情報は公開せず、本人が管理する環境で取り扱います。この案内サイトでは Google パスワードや認証情報の入力を求めません。

7. この案内サイトのホスティング

このサイトは GitHub Pages を利用します。GitHub は、訪問者が GitHub にログインしているかどうかにかかわらず、セキュリティ目的で訪問者の IP アドレスを記録・保存します。詳しくは GitHub General Privacy Statementをご確認ください。このサイト独自の広告、アクセス解析タグ、入力フォームは設置していません。

8. 変更とお問い合わせ

アクセスするデータや利用目的を変更する場合は、本ポリシーを更新し、必要な同意を得てから変更後の処理を行います。
