python

個人用のメール・文書保存、検索、分析アプリ

python は、運用者本人が使う Windows 向けアプリです。本人が許可したメールや文書を保存し、検索用の索引、分類、内容確認、分析に利用します。一般向けの利用者募集やアカウント登録は行っていません。

現在の機能

  • Gmail を読み取り専用で取得し、本文・添付ファイルを含むメールと検索索引を保存します。
  • 本文を含む検索索引のコピーを、既存の Google Drive 同期経路で保存します。
  • 本人の確認のもと、検索結果を ChatGPT で分析する補助経路があります。

準備中の機能

Google Drive の指定フォルダーにある文書の自動取得を準備しています。読み取り専用とし、アプリ側で指定フォルダー配下に対象を制限します。この機能の認証と自動運転は、まだ開始していません。

データの取り扱い

Google 原本を変更・削除するためのアプリではありません。この公開サイトに、メール本文、添付ファイル、業務文書、認証情報は掲載しません。すべての処理がパソコン内だけで完結するわけではありません。保存先や外部処理、接続解除後のコピーの取り扱いは、プライバシーポリシーをご確認ください。
